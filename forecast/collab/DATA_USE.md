# Data use: collaborator version

This folder is a private version of the U.S. Election Forecast Archive,
shared with named collaborators for research.

It includes individual forecasts from forecasters who have not yet given
permission for public release. By using these files you agree to:

1. Use them only for research with Kevin DeLuca.
2. Keep them within your research team. Share the folder link only with
   Kevin's agreement.
3. Publish per-forecaster numbers from rows marked `permission` = `pending`
   only after the forecaster has agreed to public release. Rows marked
   `public`, and the line averages in the public archive, can be used and
   cited freely.
4. Cite the archive in any work that uses it (see README.md).

The public version is at
https://github.com/kevin-deluca-polisci/KD-website/tree/main/forecast/archive/2026

Questions: Kevin DeLuca, Department of Political Science, Yale University.
