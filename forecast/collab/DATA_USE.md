# Data use: Version 0.1 (pre-release)

This folder is an early, private version of the U.S. Election Forecast
Archive, shared with a few researchers. It is not for wider release.

It includes individual forecasts from forecasters who have not yet given
permission for public release, and the raw files those forecasts were read
from. By using these files you agree to:

1. Use them only for research, and tell Kevin DeLuca what you are working on.
2. Keep them within your research team. Do not post or redistribute the files
   or the folder link.
3. Publish per-forecaster numbers from rows marked `permission` = `pending`,
   or from their raw files, only after the forecaster has agreed to public
   release. Rows marked `public`, and the line averages in the public archive,
   can be used and cited freely.
4. Respect the original sources' terms for the raw files (for example,
   Wikipedia text is CC BY-SA 4.0).
5. Cite the archive in any work that uses it (see README.md), and the
   original forecasters when you use their numbers.

Files may change between copies while the data are still being collected and
checked. The build date is in `version.txt`.

Questions: Kevin DeLuca, Department of Political Science, Yale University.
