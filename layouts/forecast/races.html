The seat that decides control

Every Senate seat, ordered from the most Democratic to the most Republican, with each one's expected margin drawn as a bar. Reading left to right, the bars are the Democrats' seats in the order they would fall. Control is not decided by the average race. It is decided by one specific race in the middle of that order, and this is a picture of which one.

{{- with .tipping_50 }}

{{ .state }} is the fiftieth Democratic seat. The model has it at {{ if gt .margin 0.0 }}D+{{ printf "%.1f" .margin }}{{ else }}R+{{ printf "%.1f" (mul .margin -1) }}{{ end }}, so {{ if gt .swing_needed 0.0 }}a uniform {{ printf "%.1f" .swing_needed }}-point move toward the Democrats nationwide would carry it, and with it a fifty-fifty Senate{{ else }}the Democrats already hold it in expectation{{ end }}.

{{- end }} {{- with .tipping_51 }}

Fifty is a tie, and a tie is broken by the vice-president, who is a Republican this cycle. The first seat that is actually a majority is the fifty-first, which is {{ .state }} at {{ if gt .margin 0.0 }}D+{{ printf "%.1f" .margin }}{{ else }}R+{{ printf "%.1f" (mul .margin -1) }}{{ end }}. A chart that draws only the fifty-line is quietly assuming a friendly vice-president.

{{- end }} {{- if $p }}

Run as a simulation rather than read off the order, the model puts the chance of the Democrats reaching 50 at {{ printf "%.0f%%" (mul $p.prob_D_50_plus 100) }}{{ with $p.prob_D_51_plus }} and of an outright majority at {{ printf "%.0f%%" (mul . 100) }}{{ end }}. Both numbers rest on the assumption that {{ $p.holdover_D }} Democratic seats carry over untouched; move that by one and the first figure moves by about twenty points.

The {{ .n_competitive }} races the model does not consider settled — New Jersey through Nebraska in the order above. The lean is our own reconstruction from official returns, not a licensed index, so these numbers are ours to publish. Nothing here knows who the candidates are, which is exactly why it disagrees with the professionals where a party has an unusually strong recruit.

Dan Osborn is running as an independent, and against a two-party model that fact simply does not exist — the number above is what a generic Democrat would be expected to do in Nebraska, which is not the race being held.
