Standard errors in parentheses. PVI is the seat's partisan lean in points: 0.75 × its 2024 presidential lean plus 0.25 × its 2020 lean, on the 2026 lines (2024 alone in states that redrew after 2024). nat_d is the national Democratic share. inc_d is +1 for a Democratic incumbent, −1 for a Republican incumbent, 0 for an open seat.

3. Uncertainty

Each race has two sources of error: how far the national vote could miss{{ with index $ft "national" }} ({{ printf "%.2f" .total_error }} points nationally{{ end }}{{ with index $ft "house" }}, {{ printf "%.2f" .nat_error_per_race }} in a House race{{ end }}{{ with index $ft "senate" }} and {{ printf "%.2f" .nat_error_per_race }} in a Senate race{{ end }}), and race-level error. Combined, the error in a single race is {{ with index $ft "house" }}{{ printf "%.2f" .total_error }}{{ end }} points in the House and {{ with index $ft "senate" }}{{ printf "%.2f" .total_error }}{{ end }} in the Senate. A race's win probability is the chance a normal distribution with that spread, centered on the prediction, lands above 50%.

Seat totals come from 10,000 simulated elections. Each simulation draws one national error shared by every race in both chambers, plus a separate error for each race. The random seed is fixed, so the same inputs give the same numbers.

Updates

Each update uses the latest national inputs: approval (the site's average of the published approval aggregators), the 2026 average gas price (EIA weekly, via FRED) and real disposable income per capita (via FRED). For dates in 2025, before any 2026 data, the gas and income terms use the change over the preceding year. Each date also uses the district maps in force on that date, so the forecast shifts when a state's new map takes effect. The coefficients stay the same. The model stops updating on November 1, 2026.
